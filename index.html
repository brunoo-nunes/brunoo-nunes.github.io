AutoShorts

AutoShorts é uma ferramenta de uso pessoal de Bruno Nunes (bruno.nn.oliv@gmail.com) que produz vídeos curtos e os envia aos canais do próprio autor no YouTube.

Política de Privacidade

O AutoShorts usa a API de Dados do YouTube apenas para enviar vídeos e ler informações básicas dos canais do próprio autor. Não coleta, vende nem compartilha dados de outras pessoas.

Os tokens de acesso ficam guardados somente no computador do autor e podem ser revogados a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Ao usar o AutoShorts você também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.
